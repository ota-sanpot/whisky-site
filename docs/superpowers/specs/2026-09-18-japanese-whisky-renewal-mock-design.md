# ジャパニーズウイスキー特化リニューアル モック 設計ドキュメント

**作成日:** 2026-09-18
**対象:** OtaSanpot/whisky-site（公開中: https://ota-sanpot.github.io/whisky-site/）
**位置づけ:** リニューアル全体のうち、最初のサブプロジェクト「モック」の設計。本番（Next.js）への移植は、モック承認後に別の設計→計画で行う。

---

## 1. リニューアルの方針（全体・決定事項）

| 項目 | 決定 |
|------|------|
| 既存サイトとの関係 | 既存 whisky-site をジャパニーズウイスキー特化にリニューアルする（公開URL・既存データは引き継ぐ） |
| 主な読者 | バー・飲食店で銘柄を選ぶ人。店の棚やメニューを見ながらスマホで引く |
| 網羅範囲 | 国内の全蒸留所＋現行の定番品。限定品・終売品は対象外（将来検討） |
| 表示基準の扱い | 基準を満たさない国産ブランドも載せ、全銘柄に基準の区分を明示する |
| トーン | 夜のバー（深い茶黒の背景×琥珀色）。暗い店内でまぶしくないこと |
| フォント | Noto Sans JP のみ（サンポット名義のルール）。既存の Noto Serif JP は使わない |
| サイト名 | 仮称「ジャパニーズウイスキー図鑑」。正式名は後で決める |

## 2. モックの目的

見た目（夜のバー）と情報の並べ方を、実在の銘柄で確かめて CEO が判断できる状態にする。
データの形・本番の技術構成はここでは確定しない（移植時に決める）。

## 3. 成果物

- `mock/index.html` の単一ファイル（CSS・JS・データをすべて内包、外部依存は Google Fonts のみ）
- ハッシュで画面を切り替える: `#/`（トップ）, `#/whisky/<id>`（銘柄）, `#/distillery/<id>`（蒸留所）
- 既存の Next.js（`src/`）には一切触らない。`mock/` は `src/app` 外なのでビルド・デプロイ対象にならない

## 4. 画面と見本の銘柄

| 画面 | 見本 | 確かめること |
|------|------|------|
| 銘柄① | 響 JAPANESE HARMONY | ブレンドの中身（公表されている原酒の蒸留所）と、その県を図で見せる |
| 銘柄② | シングルモルト余市 | 1つの蒸留所で造るシングルモルトの見せ方 |
| 銘柄③ | イチローズモルト&グレーン ワールドブレンデッド | 「海外原酒を含む」区分の見せ方 |
| 蒸留所 | 山崎蒸溜所 | この蒸留所の原酒が使われている銘柄の一覧と行き来 |
| トップ | — | 名前で検索、都道府県から探す、味から探す |

見本の銘柄が現行品でない、または公表情報が足りないと裏取りで分かった場合は、同じ型を示せる別の銘柄に差し替え、差し替えた理由を完了報告に書く。

## 5. 銘柄ページの構成

### 5.1 最初の一画面（スマホ 375×812 で、スクロールせずに見える範囲を目安）
上から順に:

1. **銘柄名**（日本語＋英字）、メーカー、種類（シングルモルト／ブレンデッド／グレーンなど）
2. **表示基準のバッジ**（5.3 の3区分）
3. **産地**: 都道府県＋蒸留所。ブレンドは原酒ごとに「蒸留所（県）」を並べる。原酒構成が非公表なら「原酒構成：非公表」と表示する
4. **味のイメージ**: 一言（例「蜂蜜とオレンジ、やわらかい甘さ」）＋味の地図（縦軸 やわらか↔濃厚、横軸 華やか↔スモーキー の2軸に点を打つ）
5. **おすすめの飲み方**: ストレート／ロック／ハイボール／水割り を ◎○△ で
6. **似ている銘柄・次の1本**: 横スクロールのカード2〜3枚（理由を一言添える）

一画面に収まりきらない場合の優先順位は 1→2→3→4→5→6。6 は一画面の下端にかかっていればよい。

### 5.2 その下（丁寧に理解する部分）
- 香り・味・余韻（メーカー公式のテイスティングノートを基本にする）
- 原酒と樽（ブレンドは「蒸留所 → 原酒の種類 → この1本」の構成図）
- 造り手と歴史（発売年、蒸留所の成り立ちなど）
- スペック表（度数・容量・熟成年数表記の有無・メーカー希望小売価格・発売年）
- 出典（参照した公式ページ等のリンクと確認日）

### 5.3 表示基準の3区分
日本洋酒酒造組合「ウイスキーにおける『ジャパニーズウイスキー』の表示に関する基準」に照らして区分する。

| 区分 | 表示 | 条件 |
|------|------|------|
| 基準適合 | 「ジャパニーズウイスキー」 | メーカーが基準に沿ってジャパニーズウイスキーと表示している |
| 海外原酒を含む | 「海外原酒を含む」 | メーカーが海外原酒の使用を公表している（ワールドブレンデッド等） |
| 未確認 | 「区分 未確認」 | 公表情報から判断できない |

バッジをタップすると、基準の要点を短く説明する（トップにも同じ説明への入口を置く）。

## 6. 蒸留所ページの構成
- 蒸留所名、所在地（都道府県・市町村）、運営会社、創業年
- 特徴（仕込み水・蒸留器・熟成環境など、公表されている範囲）
- **この蒸留所の原酒が使われている銘柄**: シングルモルト／ブレンドに分けて一覧。モックでは見本3本のうち該当するものはリンクし、それ以外は名前のみ（リンクなし）
- 出典

## 7. トップページの構成
- 検索窓: 日本語・ひらがな・英字の別名で引ける（例「ひびき」「hibiki」→ 響）。モックでは見本銘柄＋蒸留所に対して動く
- 都道府県から探す: 蒸留所のある県を並べる（モックは簡易な一覧かタイル。日本地図の本実装は移植時）
- 味から探す: 味の地図の4象限から選ぶ入口
- 表示基準の説明への入口

## 8. 内容の正確さのルール
- 事実（原酒構成・蒸留所・度数・価格・発売年・基準区分）は、メーカー公式サイト等の一次情報で裏取りしてから書く。取れないものは書かず「非公表」「未確認」とする
- 味の地図の位置・飲み方の◎○△・似ている銘柄は、サイトの見立てである。画面上に「編集部の見立て」と明記し、事実と混ぜない
- メーカー推奨の飲み方があれば、見立てとは別に「メーカー推奨」と示す
- 各ページに出典と確認日を載せる

## 9. デザイン
- 色: 背景 深い茶黒、文字 生成り、アクセント 琥珀。色は `:root` の変数で定義し、本番移植で使い回せるようにする
- 文字: Noto Sans JP のみ。見出しの品は字間とウェイトで出す。日本語に斜体は当てない
- スマホ優先（基準幅 375px）。左右の余白 16px、横スクロールは「似ている銘柄」のカード列だけ
- タブレット・PC ではコンテンツ幅を絞って中央寄せ（最大 720px 程度）
- 画像は使わない（ボトル写真の権利処理が未整理のため）。ボトルの位置には色と文字だけの簡易な図を置く
- 投稿系の文章ルールに合わせ、長いダッシュ（——）は使わない

## 10. 確認方法
- ヘッドレス Chrome で 375 / 768 / 1280 幅のスクショを撮り、全画面を目視する（被り・はみ出し・横スクロールがないこと）
- 5.1 の一画面に 1〜5 が収まっているかを 375×812 で確認する
- 検索（「ひびき」「hibiki」「山崎」）、画面の行き来（銘柄 ⇄ 蒸留所）を実際に操作して確認する
- コンソールエラーがないこと
