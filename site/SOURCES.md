# 第2版：銘柄の大幅追加（2026-09-19）

CEO提供の100銘柄リストを参考に、各メーカーの公式サイトで1本ずつ確認して96銘柄・20蒸溜所にした。各銘柄・蒸溜所の出典URLは、サイトの各ページの「出典」とデータ（index.html の wdata）に入っている。価格はCEOの指示で全銘柄から外した。

## 方針
- 対象は「現行の定番品＋今も公式に案内がある限定品」。終売品・過去の1回きりの限定品は外した
- 事実は公式ページで確認できたものだけ。原酒の中身などが書かれていない項目は「非公表」「区分 未確認」
- 味の一言・味の地図・飲み方の◎○△・次の1本は編集部の見立て（公式の説明があればそれをもとにした）
- 年齢確認のあるメーカーサイトは、CEOの許可（今回の裏取りに限り、1993年・日本）で通した。「再度表示しない」は付けていない

## 区分を2つ追加した
- 「スピリッツを含む」：ウイスキーに加えてグレーンスピリッツやブレンド用アルコールを使っていると公表（サントリーのホワイト・トリス・レッド、ブラックニッカ4種、ハイニッカ、マルス エクストラ、サンシャインウイスキー）
- 「表示基準の対象外」：麦芽を使わず米だけでつくる琉球ウイスキー「鯨」（まさひろ酒造）

## リストと公式情報の食い違い（公式に合わせた）
- ザ・ニッカ／スーパーニッカ／フロム・ザ・バレル／フロンティア／伊達／カフェモルト：公式に「輸入原酒を一部使用」
- ブラックニッカ4種・ハイニッカ：輸入原酒に加えてグレーンスピリッツも使用
- 竹鶴ピュアモルト：現在は「数量限定」の扱い
- 碧Ao：公式で名前が出ている日本の蒸溜所は山崎だけ（リストの「白州」は確認できない）
- マルス：蒸溜所名は現在「マルス駒ヶ岳蒸溜所」。越百・岩井トラディションは英国製造の原酒を含む
- 「波兎（HATOZAKI）」は公式では「波門崎」
- 碧州：公式ではカナディアン・スコッチモルト・アイラモルトのブレンド（自社モルトの記載はない）。碧南蒸留所の所在地は愛知県西尾市

## イチローズモルト（ベンチャーウイスキー）を入れられなかった理由

2026-09-25 に再確認した結果、**公式サイトそのものが無くなっていました**。

- `https://www.one-drinks.com/`（旧公式）… GoDaddy のドメイン販売ページ（パーキング）になっている
- `https://www.ichirosmalt.com/`… 「発売間近」とだけ書かれた置きページで、ベンチャーウイスキーのものと確認できない
- `venturewhisky.co.jp` など、ほかに公式と確認できるドメインは見つからなかった

このサイトは「事実は公式ページで裏取りし、出典と確認日を出す」という約束で作っているため、公式の情報源が存在しない銘柄は、産地・原酒の構成・度数・表示基準の区分のどれも裏取りできません。販売店の説明や第三者のデータベースはありますが、それらを事実の出典にするとサイトの約束が崩れます。

判断が必要な点は本文の外（CEOへの報告）に書きました。
